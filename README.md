This game was developed based on a tutorial and significantly expanded with custom features, advanced progression systems, and cinematic storytelling.
Visual Effects: Implemented a custom video effect for ghost dissipation using the Unity Particle System to enhance combat feedback.
Dynamic Difficulty: Engineered a scaling system where every 25 kills trigger an increase in difficulty, boosting enemy movement speed and spawn density.
Camera & Cinematics: Created an immersive intro cutscene using Cinemachine dynamic cameras and Timeline, featuring synchronized animations and audio tracks.
Progression & Persistence: Added a frag counter and a Persistent High Score system, including a dedicated button to reset local records.
UI/UX Framework: Developed a complete game loop with a functional Main Menu and Pause Menu for a polished user experience.
Post-Processing: Enhanced the mystical atmosphere by configuring Bloom and Vignette effects to achieve a professional visual style.

The project transitions from a basic prototype to a complete game cycle. By integrating Cinemachine for storytelling and a Progression Logic for difficulty,
the gameplay remains engaging over time. The addition of Post-Processing and Particle Systems ensures the visual quality meets modern indie game standards.
